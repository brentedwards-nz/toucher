# Toucher 🟢⚪

**Modernizing the Green: Real-Time Lawn Bowls Management**

Toucher is a multi-tenant platform designed to bring lawn bowls into the digital age. It connects players on the green with the clubhouse in real-time, simplifying everything from casual club matches to large-scale tournament administration.

## 🌟 What is Toucher?

Toucher is a "club-in-a-box" solution for lawn bowls organizations. It replaces paper scorecards and manual bracket updates with a seamless, digital experience that works across mobile devices and clubhouse displays.

### For Players & Markers
- **Live Scoring:** Enter scores end-by-end directly from the green using the mobile app.
- **Rink Assignments:** See exactly where and when you're playing.
- **Instant Updates:** Get real-time notifications for tournament draws, weather delays, or schedule changes.

### For Club Administrators
- **Tournament Management:** Easily create and manage various tournament formats (Knockout, Round Robin, etc.).
- **Membership Management:** Maintain an organized database of club members and tiers.
- **Clubhouse Dashboards:** Display live, auto-updating scoreboards on clubhouse TVs to keep spectators engaged.
- **Content Hub:** Manage club news, rules, and announcements from a central portal.

## 🚀 Key Features

- **Multi-Tenant:** Designed for use by multiple independent clubs, each with their own secure data and branding.
- **Real-Time Sync:** A score entered on the green is instantly visible on the clubhouse dashboard.
- **Mobile First:** Optimized for performance on the green, even in varying connectivity conditions.
- **Frictionless Access:** Simple login using Magic Links, Google, or Facebook—no complex passwords to remember.
